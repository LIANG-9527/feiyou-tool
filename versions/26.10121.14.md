# 26.10121.14（2026-10-12）

## 全站登录门禁 + 指纹识别只认建站系统

### 一、全站登录门禁（新功能）
- 所有页面与接口加统一登录校验：未登录访问任何页面（含直接敲地址）一律跳登录页；未登录调接口返回 401。
- 登录页账号密码校验通过后发会话 Cookie（7 天、HttpOnly、存内存——重启服务需重登）。
- 平台各页面右下角注入「退出登录」按钮；客户报告页与登录页不注入。
- 开关方式：服务器 `.env` 配 `GEO_AUTH_USER` / `GEO_AUTH_PASSWORD` 两键=门禁开启；任一留空=门禁关闭，行为与旧版完全一致。账号不入包、不落盘、不进日志，需在服务器 .env 单独放置。
- 本地脚本适配：重启冒烟、UI 冒烟、回归跑表、夜间批量四个脚本自动登录带会话（门禁关闭时空操作）。

### 二、CMS 指纹识别收窄为只认建站系统
- 识别范围剔除 Web 服务器（Tengine/Nginx 等）、CDN、编程语言这类服务器环境特征，只保留建站系统/框架/静态站点生成器/电商系统。
- 不再出现"识别为 Tengine"这类结果；识别不出建站系统时按"无法识别（可能全定制开发）"报告。
