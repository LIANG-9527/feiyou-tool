# 修订规格：检查项定级与阈值 V6 落地

> 依据：《检查项定级与阈值修订对照表_V6.xlsx》（66 项 + 3 全局规则 + 必检清单 + 界定标准三表）。
> 本规格 = 每项改动落在哪个判定、改成什么、怎么验收。批准后分批实现，每批完成即验证。
> 计票模型不变：最高档 2 票 / 重要档 1 票 / 轻微档 0.5 票；升降档只动判定结果，不动定级。

## 术语约定

- **转提醒**：该项改为"仅建议"类型——结论保留展示，标「优化机会」标签，不进计分（复用现有仅建议机制）。
- **占比类最小样本保护**：抽样有效页 <6 时，占比类判定最高只出"不足"，不判不合格。
- **字符计**：汉字/字母/数字/标点各算 1 字符，不按显示宽度折算。

## 批次〇：全局机制（先行，后续批次依赖）

| 改动 | 内容 | 验收 |
|---|---|---|
| 占比判定加最小样本参数 | 判定函数加 `min_sample=6`：有效页 <6 时问题占比再高也只判"不足"。适用于：内页标题与描述规范、内页正文厚度、内页图片说明覆盖、网址结构与可读性、时效性占比 | 构造 5 页样本全有问题→结论为"不足"；6 页全有问题→"不合格" |
| 转提醒机制 | 下列项的"仅建议"标记打开（名单见各批次），报告侧标签统一为「优化机会」、与计分项视觉区分、保留结论文字 | 转提醒项不出现在计分明细；报告带「优化机会」标签 |
| AI 项波动标注 | 参与计分的 AI 项（语义友好度、内容分块、搜索意图）结论旁标注"结论存在波动可能" | 报告中三项均带标注 |
| 相似度算法统一 | 页面雷同与关键词蚕食统一为 8 字符滑窗 Jaccard：雷同 ≥85% 记疑似、蚕食（去品牌词标题）≥70% 记疑似 | 用同一段文本两处结果一致 |

## 批次一：技术可抓取性

| 检查项 | 改动 | 验收 |
|---|---|---|
| robots.txt（重构） | ① 实现 RFC 9309 小型解析器（Allow/Disallow、`*`、`$`、最长匹配）；② 爬虫名单配置文件化：A 组检索型 15 个（搜索引擎 8：Baiduspider/360Spider/Sogou web spider/YisouSpider/ToutiaoSpider/Googlebot/Bingbot/Applebot + AI 检索 7：Bytespider/OAI-SearchBot/PerplexityBot/KimiBot/ChatGPT-User/Perplexity-User/Claude-User）任一被封→**不合格**；B 组训练型（GPTBot/ClaudeBot/Google-Extended/Cohere-AI）与存疑组封禁→**不出现在问题列表**；③ sitemap 引用子项保留计分（重要档）；④ 报告注明"UA 可伪造，结果为初判；robots 只约束声明遵守的爬虫" | 单元样例：通配符 robots 下 A 组任一被封→不合格；仅 B 组被封→该项不报封禁问题 |
| 站点地图 | 硬问题中"详情页/FAQ 未收录进地图"降为提示语不判级；其余硬问题（主机不一致>50%、index.php>50%、noindex 页留地图）维持判不足 | 构造仅"详情页未收录"样例→结论为合格+提示 |
| 页面可索引性 | 不动（最高档必检） | — |
| 网址规范化 | 新增五项机检，任一命中→**不合格**：① href 空/解析失败/含未替换模板占位符（{{、{%、%s）；② 目标注册域≠本站；③ 目标请求 404/410/5xx（跟随重定向后）；④ 目标 3xx 且最终落点≠声明值；⑤ 目标含 noindex（meta 或响应头）。注册域用内置公共后缀清单（com/net/org/gov/edu/io/ai/co/cc/top/xyz/site；com.cn 等 6 个国内二级；31 省级 cn；港澳台常见；未命中→整个 host 即注册域）。原"指向他页/缺失"=不足维持 | 构造站外 canonical→不合格；m.→www 自指→仍合格；目标 404→不合格 |
| 跳转与状态码 | 不动 | — |
| 内容可访问性 | 阶梯改为：<100 字符=不合格；100~500=不足；≥500=合格。删除 noscript 分支。报告注明"本次未检测 JS 依赖（渲染对比能力下期上线）" | 新阶梯三档各一例 |
| 响应速度与体积 | 措辞固定："HTML 文档下载耗时"，禁写"首屏/LCP"（核对现有文案已基本满足，仅统一） | 报告文案检查 |
| 移动端友好 | 保留计分；新增一条提醒：移动适配与落地页弹窗体验，引导百度资源平台 | 报告出现提醒行 |
| 网址结构与可读性 | 纯数字路径段排除日期型：4 位数字段（年份目录）及"年/月"数字段组合不计问题 | /2026/09/xxx 不再记纯数字问题 |
| 内部链接可访问性 | 不动 | — |
| HEAD/GET 一致性、分享卡片 | **转提醒** | 不进计分 |
| 缓存与会话开销 | 定级轻微档升重要档（判定逻辑不变，仍最高"不足"） | 定级变更生效 |
| 安全响应头 | 维持不计分；文案注明"价值在等保合规而非排名" | 文案检查 |
| 首选域统一 | 不动 | — |
| 站内搜索/分页/CMS 指纹/后台路径 | 维持；后台路径报告注明"主动探测可能被 WAF 记录" | 文案检查 |

## 批次二：AI 友好度

| 检查项 | 改动 | 验收 |
|---|---|---|
| Meta Title（双轴重构） | 轴1：无 title=不合格；1~14 字符=不足；15~30=合格；>30=合格+截断提示（"重要信息前置"）；>60=追加改写风险提示（不判级）。轴2 堆砌（任一→不合格）：① 分隔符（_ | 、,，/\\- 等）切分 ≥6 槽且 ≥5 槽为 1~2 词裸关键词；② 同一关键词/词根重复 ≥3 次。纯英文站可配置切换 60/160。首页与内页抽同一公共函数 | 三轴样例各一：正常/过短/堆砌 |
| Meta Description | 无=不足（降档，原不合格）；1~49=不足；50~80=合格；>80=合格+截断提示；**删除行动号召词规则**；英文站可配 160；同公共函数 | 缺失→不足（原不合格）；无 CTA 正常描述→合格 |
| 内页标题与描述规范 | 与首页同一套函数与阈值（含堆砌轴）；占比判定受最小样本保护 | 与首页同函数单测 |
| 大标题层级、结构化数据（删除"全无=不合格"、高价值类型清单移除 FAQPage）、面包屑、站内链接丰富度、内页 H1 唯一性、详情页结构化数据 | **转提醒** | 不进计分 |
| 站长平台验证 | 轻微档升重要档；文案注明"验证标签≠已提交 sitemap" | 定级+文案 |
| 其余（AI 答案格式、唯一性、语义、分块） | 保留；AI 答案格式计数口径补 details 标签 | — |

## 批次三：内容质量

| 检查项 | 改动 | 验收 |
|---|---|---|
| 核心内容深度 | 不动 | — |
| 时效性与原创性（拆分） | 计分部分=时间标注占比：信号三来源（time[datetime]、article:published/modified/og:updated、正文可见"发布/更新+日期"正则）；占比 ≥80%=合格、30~80%=不足、<30%=不足（高优先提醒，永不不合格）；站点地图 lastmod 同日占比 ≥50%→封顶"不足（疑似批量回填）"。AI 原创性结论转提醒展示 | 占比三档样例；lastmod 同日封顶样例 |
| FAQ 问答结构（拆分） | "有问答板块"计分：有=合格、无=不足；"缺 FAQPage 标记"转提醒 | 板块与标记分离样例 |
| 图片与多媒体优化（逻辑重写） | 三态：写清说明=好；留空=对（剔除分母，明细提示"如为信息图请补说明"）；错=无 alt 属性/占位词（≤2 字符或"图片/image/img/photo/pic/照片"）/模板残留。判级只看该写说明的图：≥80%=合格、50~80%=不足、<50%=不合格。坏文件名独立提示不进判级。内页图片说明覆盖同步同口径（受最小样本保护） | 留空图多的合规站→合格；该写未写过半→不合格 |
| 内链锚文本、关键词蚕食 | **转提醒**（蚕食标注"规则初筛，需人工确认"，换 8 字符滑窗） | 不进计分 |
| 搜索意图匹配 | 保留 | — |
| 内页正文厚度 | 保留；受最小样本保护 | 5 页样例→不足 |
| 必备页面完备性 | 隐私政策从强必备移到提醒；强必备剩 3 类（关于、产品/服务、FAQ）：缺 0=合格、缺 1~2=不足、缺 ≥3=**不足**（永不不合格） | 缺 3 类样例→不足 |
| 页面与首页雷同 | 无 AI 时机械判定统一降一档：≥3 对也只判不足 | 无 AI+3 对→不足 |
