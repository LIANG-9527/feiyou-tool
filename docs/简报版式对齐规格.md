## 1. 目标

情报简报不再 8 页同一版式，改为**一页一套专属版式**，构件对齐参考稿。内容不新增采集：全部从既有调研 JSON（mr_profile ~ mr_sales 六章正文、mr_brief 结构、mr_deck）里取；取不到的数字一律填「待补充」。

三条已确认前提：
1. 基本面页保持拆出，归企业画像页签；简报固定 8 页。
2. 版式构件直接从调研正文章节渲染，不扩采集 skill。
3. 缺的数字（如 GEO 适配度分值、预算估算值）用「待补充」占位，禁止编造。

## 3. 数据契约（mr_deck 输出 schema 变更）

现：`{"slides":[{"k","t","p","items[]"}]}`（单一形状，装不下构件）

改为每页带 `blocks` 数组，块型有限集、渲染器按型分发：

```json
{"slides":[{"k":"01 · 经营模式","t":"结论式标题",
  "blocks":[
    {"type":"two_col","cards":[{"title":"💰 盈利方式","rows":[["出厂差价","赚差价（核心）"]]},
                               {"title":"🧲 获客渠道","rows":[["卖场客流","降40-60%（推断）"]]}]},
    {"type":"timeline","items":[["2015","上交所主板上市"]]},
    {"type":"words","cols":[{"title":"🟢 正面词","chips":[{"w":"原态环保","src":"小红书抽样"},{"w":"设计不错","src":"推断"}]},{"title":"🔴 负面词","chips":[{"w":"增项收费","src":"黑猫投诉案例"}]}]},
    {"type":"table","head":["意图组","出现率","Top1"],"rows":[["本地到店","待实测","待实测"]]},
    {"type":"bars","items":[{"name":"整家定制","score":85,"note":"基本盘"}]},
    {"type":"media","groups":[{"title":"🌐 线上","rows":[["SEM投放","y","巨额投入"],["AI GEO","n","空白"]]}]},
    {"type":"kws","cols":[{"tier":"防守词","desc":"先做","chips":["好莱客怎么样"]}]},
    {"type":"note","text":"突破口：健康旧改意图组"},
    {"type":"src","text":"来源：2023年报口径"}
  ]}]}
```

块型固定 8 种：two_col / timeline / words / table / bars / media / kws / note + src。score 取不到写 null，渲染为「待补充」。words 的 chip 允许纯字符串（无来源=按「推断」样式）或 {w,src} 对象。

- 改 skills/15_mr_deck.yaml 的输出格式与纪律段（保留"待实测/待补/（推断）"三标注）。
- 模型输入已含全部章节正文，无需改 skill 链。

## 5. 边界

- **Always**：blocks 块型白名单校验，未知块型降级为 note；数字缺失只写「待补充」；转义渲染。
- **Ask first**：改 mr_profile/mr_brief（企业画像页签）任何内容。
- **Never**：动 output/ 历史数据；扩采集 skill；编造适配度分值/预算数字。

## 6. 验收标准

1. 重跑一次好莱客调研（或仅重跑情报简报步骤），8 页各呈现 §2 表的专属版式，无一页退化为纯列表。
2. 所有无据数字显示「待补充」，所有出现率类显示「待实测」，页页有来源行。
3. 历史已生成报告打开不破版（旧 schema 兼容路径生效）。
4. 企业画像页签、完整背调报告页签渲染零变化。
