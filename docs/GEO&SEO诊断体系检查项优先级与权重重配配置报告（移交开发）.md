# 开发实现约束

## 数据结构变更

在每个检查项结果对象中新增以下字段，原有字段全部保留不动：

```json
{
  "id": "tech-02",
  "name": "robots.txt",
  "category": "技术可抓取性",
  "tier": "core",
  "priority": "P0",
  "tags": ["SEO", "GEO"],
  "score_in_total": true,
  "conditional": null,
  "status": "warn",
  "score": 0.5,
  "message": "...",
  "manual_check": "...",
  "purpose": "...",
  "impact": "...",
  "scope": "...",
  "applicable_pages": "...",
  "suggestion": "...",
  "excellent": "...",
  "normal": "...",
  "failed": "..."
}
```

|字段名|类型|必填|说明|
|---|---|---|---|
|**tier**|string|是|core=核心项（参与核心得分），bonus=锦上添花项（不参与核心得分）|
|**priority**|string|是|P0阻断级 / P1重要 / P2一般 / P3参考|
|**tags**|array|是|多标签，可选值 \["SEO"\] / \["GEO"\] / \["SEO","GEO"\]|
|**score\_in\_total**|boolean|是|是否参与总分计算。tier=core时为true，tier=bonus时为false|
|**conditional**|string/null|否|条件化校验规则标识。null=无条件始终执行；如 "multilingual\_only"=仅多语言站点执行，"tech\_b2b\_only"=仅技术型B端执行|

## 评分计算规则

1. **原有5分类权重保持不变**（技术0\.3 / AI友好0\.3 / 内容0\.2 / 权威0\.15 / 商业0\.05），用于原始总分计算，不改动。

2. **核心得分**：仅统计 tier=core 且 score\_in\_total=true 的检查项，按原有权重加权计算。锦上添花项不参与核心得分。

3. **展示总分**：维持现有total\_score不变（含所有项），新增 core\_score 字段输出核心得分。UI同时展示两个分数，核心得分为主。

4. **等级评定**：grade 基于 core\_score 评定，而非 total\_score。

## 前端渲染规则

1. **顶部分类切换**：Tab切换「分类A：SEO检查集」/「分类B：GEO检查集」，切换后按tags过滤检查项，模块标题与副标题随分类动态切换。

2. **问题分层展示**：检查结果按 tier 分两组展示——「核心问题」（tier=core且status=warn/fail）置顶，「可选优化建议」（tier=bonus）折叠展示，避免低价值告警淹没阻断性缺陷。

3. **条件化项跳过**：conditional 字段触发跳过时，该检查项不展示告警，仅在「已跳过检查」区域列出跳过原因（如"单语言站点，已跳过多语言检查"）。

4. **加分项处理**：b2b\-04对比类内容为加分项，status=pass时在核心得分基础上额外加0\.5分（上限不超过该项满分），status=warn/fail时不扣分。

## 条件化校验规则清单

|检查项ID|conditional标识|触发条件|跳过逻辑|
|---|---|---|---|
|content\-06|multilingual\_only|检测到页面存在语言切换按钮或hreflang标签|单语言站点直接跳过，不产生告警；多语言站点正常执行hreflang完整性检查|

|content\-02|time\_label\_conditional|页面类型为资讯/文章/博客|产品/方案/案例等静态商业页不强制要求发布时间标注，不扣分；资讯类页面正常检查|

# 验证与交付标准

1. **数据完整性**：46项正式检查项全部配置 tier/priority/tags/score\_in\_total 字段，无遗漏。

2. **评分一致性**：core\_score 仅由36项核心项计算得出，10项锦上添花项不参与；total\_score维持原算法不变。

3. **分类过滤正确性**：切换SEO分类时，llms\.txt\(tech\-04\)、\.well\-known\(tech\-05\)、AI答案格式\(ai\-05\)、NLP语义\(ai\-09\)、内容分块\(ai\-10\)等GEO独有项不出现；切换GEO分类时全部46项均出现。

4. **条件化跳过**：单语言站点content\-06不产生告警；普通B端b2b\-05不产生告警。

5. **UI分层**：核心问题与可选优化建议视觉隔离，锦上添花项默认折叠。

**移交确认**：本报告覆盖46项检查点的完整重配、双分类归类、数据结构变更、评分规则、前端渲染规则和条件化校验清单，开发可直接据此实施。原有检测逻辑、result数组结构、5分类权重均不做破坏性改动，仅新增字段和展示层调整。
