# 报告展示规则（首屏概述与问题卡）

> 本文档记录 GEO 官网诊断报告首屏（「30 秒看懂这份报告」板块）已定版的展示规则。
> 改动报告首屏文案或问题卡逻辑前，先对照本文档；改完规则要同步更新这里。
> 定版时间：2026-09-10，来源：客户逐条确认。

## 一、统一用语

- 检查状态只有三个词：**合格 / 不足 / 不合格**。
- 禁止使用「未达标」「不达标」等口径外的说法。
- 项目类型只有两个词：**必检项目**（参与计分）、**非必检项目**（只给建议、不计分）。
- CMS 诊断项（CMS 指纹识别、后台路径暴露检测）不在首屏概述与问题卡中出现。

## 二、首屏概述话术（两个分支）

分支判断按顺序执行两条规则：

- **规则 1**：检查有无必检项目不合格——只要有必检项目不合格，就走分支一；
- **规则 2**：必检项目全都合格时，检查有没有必检项目存在不足——有不足就走分支二。

### 分支一：有必检项目不合格

```
本次合计体检 {合计} 项（其中 {必检数} 项必检项目，{非必检数} 项非必检项目），当前有 {不合格数} 项必检项目不合格，这些环节正在影响 AI 搜索引擎对您网站内容的理解与引用。优先修复以下 {卡片数} 个关键问题，可快速提升 AI 可见度。
```

- {不合格数} 只统计**必检项目**中状态为「不合格」的数量；非必检项目的不合格不进这句。
- 问题卡从「全部必检不合格项 + P1 级不足项」里挑，最多 3 张。

### 分支二：必检项目全部合格，存在必检项目不足

```
本次合计体检 {合计} 项（其中 {必检数} 项必检项目，{非必检数} 项非必检项目），当前有 {不足数} 项必检项目存在不足，优先调整优化以下 {卡片数} 个关键问题，可提升 AI 引用概率。
```

- {不足数} = 必检项目中状态为「不足」的数量。
- 问题卡改从**必检项目的不足项**里挑（挑法与分支一相同：优先级高者在前），最多 3 张。
- 「挑不出不足项」的情况目前未出现，暂不设兜底文案。

## 三、数字口径

| 数字 | 口径 |
|------|------|
| 合计 | 必检项目数 + 非必检项目数（不含诊断项） |
| 必检数 | 参与计分的检查项数量 |
| 非必检数 | 不计分、只给建议的检查项数量 |
| 不合格数 / 不足数 | 只统计必检项目 |

## 四、问题卡格式（已定版，勿随意改动）

卡片从上到下：

1. **标题**：`{序号}. {检查项名称}`（如「1. E-E-A-T 内容可信度信号」），使用检查项正式名称，不用生意话术做标题。
2. **红色 tag**：与原版同款——限宽（220px，宽屏 300px）、单行、超长截断出省略号、**高度固定不换行**；内容顺序为「结论；描述」连排（结论在前）。
3. **悬浮提示框**（鼠标悬停红 tag 弹出）：
   - 第一行 = 结论，**加粗、15px**；
   - 换行后 = 完整描述，12px，分号处自动换行。
4. **来源标签**：紫色（「来源：」+ URL），在红 tag 之外，保持原有渲染不变。
5. **下方两卡**：「对 SEO / GEO 的影响」与「修改示例（改前 → 改后）」，维持原有内容与布局。

## 五、全站扫描明细面板（2026-09-10 定版）

- 位置：「30 秒看懂这份报告」卡片**下方**、问题卡**上方**；不放在页头 LOGO 区与 Hero 之间。
- 样式：与「报告详情」折叠卡**同款**——左侧 40px 圆角图标块 + 标题（16px 加粗）+ 副标题（12px 灰字，格式「N 页全站轻量扫描 · M 个异常，点击展开」）+ 右侧展开/收起箭头；圆角 16px、内边距 20/24、同款阴影；与上下卡片的间距与其他板块一致（下方间距 24px）。
- 默认状态：**收起**（`<details>` 不带 open），点开展开全站明细，不影响正常浏览习惯。
- 无轻量扫描数据时整个面板不渲染，不占版面。

> 附注（未定版，仅记录现状）：概述话术末尾的「另对全站 N 个页面做了轻量扫描……明细见下方『全站扫描明细』按钮」一句，是轻量扫描功能上线时由代码在两个分支话术后**统一追加**的后缀，**不属于上文两个分支的定版话术**；是否纳入定版待客户确认。

## 六、落点

- 代码位置：`site_audit/report/html_report.py`
  - 概述话术与分支判断：`generate_html_report` 内「客户版首屏」注释块；

  - 全站扫描明细面板：`_light_scan_panel`（插入位置在首屏概述卡片之后）。
- 修改本规则后必须同步更新本文档，并在历史报告上重渲染验证。

## 六、2026-09-10 追加规则

- **只提醒项**：报告统一标「优化机会」标签（琥珀色），与计分项视觉区分；结论文字保留。
- **计分 AI 项**（语义友好度、内容分块、搜索意图匹配）：结论下固定标注"（AI 判定项：两次诊断的结论可能存在波动，供参考）"；未检查的项不标。
- **问题卡置顶**：可信与安全信号、内容可访问性两项（国内语境最硬）无论不足多轻，进问题卡候选并排序置顶。
- **概述话术数字口径不变**：合计=必检+非必检（诊断项不计入、不出现）。

## 七、概述话术细则（2026-09-10 二次定版）

- 不合格数与问题卡数分开表述：卡池含置顶提醒卡时，加"另有 N 项重点优化建议"，避免"1 项不合格、修 2 个"的数字打架。
- 单复数跟随事实：1 项不合格用"该环节正在影响"，多项才用"这些环节正在影响"。
- 轻量扫描句用"快速核验"措辞，不与"体检"撞词；页面数与检查项数分句呈现。
- 已核实全站扫描明细卡片渲染在概述话术下方，"见下方"指引正确。
