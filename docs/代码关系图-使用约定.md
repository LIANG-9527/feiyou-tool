# 代码关系图使用约定（graphify）

> 用途：改代码前先查关系图确认影响面，不再靠临时 grep 枚举调用方（2026-09-19 定版）。

## 建图 / 更新
- 大改后重建（纯本地 AST，不联网）：
  `graphify extract . --code-only --out graphify-out && mv graphify-out/graphify-out/graph.json graphify-out/`
- 产物不入 git（.gitignore 已排除）。

## 查询（改前必查）
- `graphify explain "函数名"` —— 该函数的全部调用方/被调用方（含行号）
- `graphify affected "函数名"` —— 改动会波及哪些节点（反向遍历）
- `graphify path "A" "B"` —— 两个概念怎么连起来的
- `graphify god-nodes` —— 架构枢纽节点（改动高危区）

## 边界
- 图只覆盖 Python 结构；main.py 等文件里内嵌的 HTML/JS（页面交互）不进图，前端改动仍需人工过。
