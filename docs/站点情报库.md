## 一、JS 站三种形态（"200 不等于有内容"）

| 形态 | 站点 | 实测表现 | 含义 |
|---|---|---|---|
| 404 明拒 | 安克创新（anker.com.cn） | posts 文章页默认 UA 和浏览器 UA 都 404；brands 403 | 内容页是 JS 路由，静态抓取拿不到，直接被拒 |
| 200 空壳 | 36氪（36kr.com） | 所有页面返回 200，但正文仅 56 字符、标题全空 | 最迷惑——看着"正常"，实际内容全在 JS 里，静态抓取拿到的只是空壳 |
| 正常可抓 | 飞柚（feiyougeo.cn）、拓竹、Worktile | 正文能抓到且内容真实不同 | 内容在服务端 HTML 里，静态抓取可用 |

**关键教训**：**HTTP 200 ≠ 有内容**。一个站如果"返回 200 但正文异常短/标题全空"，大概率是 JS 渲染站。

**改进需求（备着，本轮不碰不扩）**：识别"大面积正文异常短 = 疑似 JS 渲染站"。下轮任务再做。

> Anker 和 36氪 只作情报归档，**不进**校准名单。

## 二、正文近重复机制验证（已完成，用飞柚做基底）

- 基底：飞柚两篇真实正文（资讯 27 段 + 案例 40 段），两篇内容确认不同（正文相似度仅 13%）。
- 三档整段复制（真实段落、模拟人工换内容、多档位）实测：
  | 复用比例 | 整页相似度 |
  |---|---|
  | 完全不同（对照） | 10% |
  | 共享 15% | 22% |
  | 共享 40% | 37% |
  | 共享 70% | 53% |
  | 共享 90% | 69% |
  | 完全相同（正本 vs 副本） | 100% |
- **结论**：机制工作正常（单调、断崖清晰、真实段落基底）。差异只在"两篇正文长度不对称时，同比例共享算出的相似度偏低"。
- **红线**：合成数据只验证机制没洞，**不准据此定正式分数线**——分数线等真实站校准那步。
