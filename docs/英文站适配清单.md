# 英文站/多语言站适配清单

> 2026-09-09 全站双语化审查产出。背景：ZSTEK（英文站）体检暴露出部分检查项只用中文词根扫站内文本，导致英文站误报（最典型：决策信息误报 0/5）。本文档记录每一处文本类检查的双语化状态，供后续维护与新增检查项时对照。
>
> **新增/修改文本类检查的铁律：凡扫站内文本（正文/锚文字/页脚）的正则，必须中英双语词根齐备**；扫 URL 路径段的至少中英+拼音。

## 三、已知边界（有意不做、或需注意）

1. **"Help Center / Support" 类叫法**：会归入「帮助文档」类型而非 FAQ 类型——语义相近但不算误报；FAQ 词根已含 question，正常 FAQ 页均能命中。
2. **ICP 备案对海外站不适用**：auth-01 可信信号三项制（备案/联系/隐私），海外站最高只能拿到 2 项，会显示"可信信号不足"的 WARN。属于口径问题而非误报，是否对非中国站免查 ICP 待业务定夺。
3. **AI 语义层检查**（搜索意图、内容原创性、语义友好度等）：由大模型完成，天然双语，不受词根影响。
4. **决策信息·价格一项**：OEM/报价制 B2B 站不标价属正常，报告会提示"可补充：价格/费用"，属建议而非误报。

## 四、新增检查项时的自查口诀

扫文本 → 问自己：**中文词有吗？英文词有吗？拼音词要吗？**（URL 路径段场景拼音必加）
